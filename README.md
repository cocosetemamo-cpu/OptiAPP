## Características

- Interfaz a pantalla completa, sin barra de direcciones
- Gestor de descargas integrado con notificaciones
- Navegación interna, incluso con enlaces externos
- Pantalla de reconexión cuando no hay internet

## Instalación

Descargá el APK desde la [última versión](https://github.com/cocosetemamo-cpu/OptiAPP/releases/latest) e instalalo. Si Android lo pide, habilitá la instalación de aplicaciones desconocidas.

**Requisitos:** Android 8.0 o superior.
