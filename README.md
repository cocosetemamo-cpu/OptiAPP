## Características

- Interfaz a pantalla completa, sin barra de direcciones
- Gestor de descargas integrado con notificaciones
- Navegación interna, incluso con enlaces externos
- Pantalla de reconexión cuando no hay internet
- Sin selección de texto ni menú contextual, para una experiencia tipo aplicación

## Instalación

1. Descargá el APK desde la [última versión](https://github.com/cocosetemamo-cpu/OptiAPP/releases/latest).
2. Abrilo desde la notificación o la carpeta Descargas.
3. Si Android lo solicita, habilitá la instalación de aplicaciones desconocidas.
4. Tocá **Instalar**.

**Requisitos:** Android 8.0 (API 26) o superior.

## Compilación

El APK se genera automáticamente con GitHub Actions en cada cambio sobre `main`.
Las versiones publicadas se crean al subir un tag con formato `vX.X`.
